# Ducumentation langage Go

## Installation de Go

Avant de commencer j’installe l’extention Go pour le language golang et je tape sa dans la bar de recherche : >Install/update Tools

Je lance un cmd et je rentre cette commande : go install golang.org/x/tools/gopls@latest


Dans un dossier go il faut que ses 3 fichiers sois crée : bin ; pkg ; src

## Création du premier projet

On vas créer une arborescence de projet : 
Cd src 
go mod init starwars

Il faut activer dans les paramètres format on save en fesant ctrl + , 

On retourne sur VS code et ouvre le dossier starwars qui se trouve à ce chemin : C:\Users\Utilisateur\go\src

Ensuite il propose de crée un fichier json, on clique pour le crée et on ajoute ce contenu qui a dans le cours de Mr BERTIN.
